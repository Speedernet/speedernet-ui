# @speedernet/ui

Bibliothèque de composants Angular de Speedernet (paquet `@speedernet/ui`), utilisée par les applications intranet. Elle regroupe les composants, les styles et les ressources (polices, logos) du design system.

Le paquet est publié sur le registre privé `https://verdaccio.speedernet.io`.

## Lancer la démonstration

```bash
npm install
npm start
```

L'application de démonstration s'ouvre sur http://localhost:4200.

## Tester

```bash
npm test
npm run build:ui
```

## Formater

```bash
npm run format
```

## Publier

La publication d'une version est décrite dans la tâche 14 du plan (Changesets). Elle n'a lieu qu'après validation de la démonstration.
